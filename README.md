# Gantt Viewer

Просмотрщик и редактор диаграмм Ганта для файлов Microsoft Project (.xml) на macOS — с AI-ассистентом, который умеет отвечать на вопросы по плану, вносить изменения и генерировать новые планы из текстового описания.

> Работает локально: файлы никуда не отправляются, кроме запросов к выбранному вами AI-провайдеру.

## Возможности

**Диаграмма Ганта**
- Открытие MS Project XML: задачи, суммарные задачи, вехи, длительности, проценты
- Связи-предшественники, критический путь, прогресс-бары
- Масштабы: дни / недели / месяцы; сворачивание веток
- Ресурсы: сводная загрузка людей, отпуска (в т.ч. импорт из Confluence)

**AI-ассистент**
- Чат по плану: вопросы и правки («сдвинь тестирование на неделю», «добавь задачу…») — изменения приходят готовым XML и применяются в один клик
- Генерация нового плана из текстового описания
- Виден ход рассуждений модели до финального ответа
- Остановка генерации кнопкой Stop
- Любой OpenAI-совместимый провайдер: OpenAI, локальная Ollama или собственный шлюз — настраивается в приложении

**Надёжность**
- Версии файла: авто-снапшоты при сохранении и AI-правках, откат в один клик, история до 5 версий
- Сохранение перезаписью и «Сохранить как…» (нативные диалоги macOS)
- Поддержка корпоративных сетей: self-signed сертификаты и VPN-инспекция SSL

## Установка

Скачайте `Gantt-Viewer-<версия>-universal.dmg` со страницы [Releases](../../releases), перетащите приложение в /Applications. Универсальная сборка: Apple Silicon и Intel.

## Сборка из исходников

```bash
npm install
npm run build:web   # Next.js статический экспорт → out/
npm run dist        # electron-builder → dist/*.dmg (universal)
```

Требования: Node.js ≥ 20, Xcode Command Line Tools.

## Настройка AI

При первом запуске создаётся конфиг `~/.config/gantt-viewer/ai-config.json` — там же его можно править через **Настройки** в приложении. Для каждого провайдера указываются:

| Поле | Описание |
|---|---|
| `baseURL` | базовый адрес OpenAI-совместимого API (если оканчивается на `/v1`, `/v4` и т.п., приложение дописывает только `/chat/completions`) |
| `apiKey` | ключ, передаётся как `Authorization: Bearer …` |
| `models` | доступные модели, одна из них — активная |
